## 添加新 Skill

1. 把 skill 目录复制到本仓库
2. 在 README 对应的分类表格中添加一行
3. 如果是新类别，新建一个 `###` 章节
4. 提交并推送

## 同步回本地

```bash
# 全量同步（不覆盖已有）
cp -r skills-for-myself/*/ ~/.claude/skills/ --no-clobber

# 同步单个 skill
cp -r skills-for-myself/skill-name/ ~/.claude/skills/
```
